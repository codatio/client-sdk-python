# BilledToType1

Defines if the bill or bill credit note is billed/rebilled to a project.

## Example Usage

```python
from codat_lending.models.shared import BilledToType1

value = BilledToType1.UNKNOWN
```

| Name             | Value            |
| ---------------- | ---------------- |
| `UNKNOWN`        | Unknown          |
| `NOT_APPLICABLE` | NotApplicable    |
