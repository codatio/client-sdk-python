# AccountType

The type of bank account e.g. checking, savings, loan, creditCard, prepaidCard.

## Example Usage

```python
from codat_bankfeeds.models.shared import AccountType

value = AccountType.CHECKING
```


## Values

| Name           | Value          |
| -------------- | -------------- |
| `CHECKING`     | checking       |
| `SAVINGS`      | savings        |
| `LOAN`         | loan           |
| `CREDIT_CARD`  | creditCard     |
| `PREPAID_CARD` | prepaidCard    |
